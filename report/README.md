# Project Report

This folder contains the public portfolio version of the **AIoT Smart Home ESP32-S3** technical report.

The report documents the design, implementation and evaluation of a modular smart home simulation developed with **ESP32-S3**, **Wokwi**, **Arduino/C++**, **Blynk** and an optional **Edge Impulse-inspired environmental classification layer**.

## Included Report

- [Download the public technical report](./aiot_smart_home_public_report.pdf)

## Report Overview

The report covers:

- Modular smart home architecture
- Bedroom automation logic
- Kitchen and living room safety logic
- ESP32-S3 room-level controller design
- Wokwi simulation implementation
- Blynk dashboard interaction
- Virtual pin mapping
- Edge Impulse environmental safety classifier
- Dataset creation and labelling
- Evaluation results
- Ethical, privacy and security considerations
- Limitations and future work

## Public Portfolio Version

This version has been adapted for GitHub and portfolio publication.

Academic submission material, personal identifiers, private credentials and sensitive submission-only content have been removed.

Public dashboard screenshots and virtual-pin mapping figures are retained where they help explain the technical architecture and do not expose private tokens, private URLs or personal data.

## Privacy and Security Notes

The public repository does not include real Blynk authentication tokens, Wi-Fi passwords or private API credentials.

Any authentication PINs or secret words shown in the public code or report are demonstration values used for simulation purposes only.

Before using this project with real hardware or real cloud dashboards, replace all placeholder credentials with private values and avoid committing them to a public repository.

## Limitations

This report describes a simulation-based prototype.

The gas thresholds, environmental classification logic and emergency responses are designed for demonstration and educational purposes. A real deployment would require physical sensor calibration, electrical safety checks, hardware validation and testing with real environmental data.
