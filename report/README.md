# Public Technical Report

[`aiot_smart_home_public_report.pdf`](./aiot_smart_home_public_report.pdf) is the concise, recruiter-facing report for the hardened public repository.

It is generated deterministically from [`../scripts/build_public_report.py`](../scripts/build_public_report.py) and is intentionally much smaller than the earlier academic portfolio adaptation. The current report prioritises:

- exact public runtime semantics;
- offline-first Wokwi behaviour;
- transparent separation between deterministic safety logic and optional ML inference;
- the simulated/rule-labelled nature of the dataset;
- historical Edge Impulse evidence without overclaiming exact reproducibility;
- pinned CI/build evidence;
- security, licensing and real-world limitations.

To regenerate it locally:

```bash
python -m pip install reportlab==5.1.0
python scripts/build_public_report.py
```

CI rebuilds the PDF and fails if the generated bytes differ from the committed report, preventing documentation drift.
