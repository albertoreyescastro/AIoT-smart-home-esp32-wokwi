# Project Report

This folder contains the public portfolio version of the **AIoT Smart Home ESP32-S3** professional technical report.

- [Open the public technical report](./aiot_smart_home_public_report.pdf)

The report documents the simulation architecture, Bedroom and Kitchen/Living Room controllers, persistence-gated environmental logic, optional Blynk monitoring, historical Edge Impulse/TinyML experimentation, evaluation evidence, ethics/privacy/security considerations and limitations.

The public report does not claim physical-hardware deployment, calibrated safety thresholds or independent real-world ML validation. Historical platform screenshots are labelled as such, and current public-runtime semantics distinguish deterministic actionable state from optional advisory ML telemetry.

The authored LaTeX source package is retained separately from this public repository to avoid duplicating the report's large figure set. Report changes are made from that source and then the reviewed PDF is replaced here.

No real Blynk tokens, Wi-Fi passwords or private API credentials are intentionally included. Visible PINs/secret words are demonstration values only.
