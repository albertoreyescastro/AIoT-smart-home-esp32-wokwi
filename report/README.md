# Project Report

This folder contains the public portfolio version of the AIoT Smart Home technical report.

The report describes a modular ESP32-S3 smart home simulation developed with Wokwi, Arduino/C++, Blynk and an optional Edge Impulse-inspired environmental classification layer.

## Included Report

- [`aiot_smart_home_public_report.pdf`](aiot_smart_home_public_report.pdf)

## Public Version Notes

This version has been sanitised for GitHub and portfolio publication. Academic submission material, personal identifiers, private links, dashboard screenshots and detailed virtual-pin mapping figures have been removed.

The full implementation is documented in the repository source code and module README files.
